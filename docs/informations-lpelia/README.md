# Dossier de collecte des informations du LPELIA

Ce dossier sert à rassembler les informations de référence sur le **Lycée Professionnel d'Électronique et d'Informatique Appliquées de Treichville (LPELIA)** afin d'améliorer l'assistant LPELIA-ACCUEIL.

## Comment contribuer

1. Ouvrez le fichier correspondant au sujet.
2. Cliquez sur le crayon **Edit this file** dans GitHub.
3. Ajoutez les informations connues ou recopiez des documents officiels.
4. Cliquez sur **Commit changes** pour enregistrer.
5. Si possible, indiquez la source et la date de vérification.

Vous pouvez ajouter ici des fichiers Markdown, texte, PDF ou des images de documents utiles. Pour chaque document, indiquez ce qu'il confirme.

## Règles importantes

- Privilégiez les documents officiels et les informations confirmées par l'administration.
- Pour les informations changeantes (frais, dates, conditions d'admission, filières ouvertes), ajoutez l'année scolaire ou la date de vérification.
- Distinguez les faits confirmés, les informations à vérifier et les explications générales.
- N'ajoutez pas de données personnelles sensibles d'élèves, de mots de passe ou de numéros de pièces d'identité.
- Ne publiez pas de coordonnées personnelles d'un membre du personnel sans autorisation.
- Ajouter un document ici ne signifie pas automatiquement que l'application en production l'utilise déjà. Après collecte, le contenu devra être intégré à la base de connaissances utilisée par le moteur de LPELIA-ACCUEIL.

## Statut initial

Les fichiers de ce dossier sont des modèles à remplir. Les champs non documentés ne sont pas des faits officiels.
